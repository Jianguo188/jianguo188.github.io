M18: Supervised vs. Unsupervised Learning

When should we teach a model using examples with known answers, and when should we ask it to find patterns for us? This guide explains the distinction and compares two ways to organize text: topic modeling and clustering.

By the end, you should be able to: distinguish supervised from unsupervised tasks; decide which approach fits a data problem; and explain how topic modeling differs from cluster analysis.

1. The big picture

Machine learning uses examples to find patterns or make predictions. The crucial question for choosing an approach is: Do you already have the answers or labels you want the model to learn?

Supervised: learn from examples with answers

Give the model input data and known target labels. It learns to predict those targets for new examples.

Think: “Here are examples and the correct answers. Learn the pattern.”

Unsupervised: explore data without target labels

Give the model descriptive features and ask it to find patterns, groups, or useful summaries without a pre-assigned answer for each item.

Think: “Here is the data. What structure might be in it?”

Memory cue: Supervised learning has examples of what to predict; unsupervised learning explores what patterns are present.

2. Key terms in plain language

  • Observation: one item or case, such as one customer review or one fruit.
  • Feature (X): information describing an observation, such as words in a review, its length, or its star rating.
  • Label or target (Y): the answer we want a supervised model to learn, such as “positive” or “negative.”
  • Training data: examples used to fit a model. For supervised learning, the training examples include labels.
  • Corpus: a collection of text documents.
  • Embedding: a numerical representation of a word, sentence, or document that can be used in later analyses.

A compact way to remember supervised data is X plus Y: inputs plus known target outputs. An unsupervised task generally starts with X without supplied Y labels.

3. Supervised learning: teach with labeled examples

Suppose you have pictures of apples and bananas. You label examples as “apple” or “banana,” then provide the pictures and labels to a model. The model learns patterns in the input that help it predict a label for a new picture.

  1. Define the outcome you want to predict.
  2. Collect representative examples with reliable labels.
  3. Train a model on the input features and labels.
  4. Check its predictions on examples it did not train on.
  5. Use it for new cases only when its performance is adequate for the task.

For text, labels might be a review’s sentiment, a support message’s department, or whether a document contains a particular category. The labels tell the model what “correct” means for this task.

Label quality matters: if human labels are inconsistent, biased, or do not match the intended task, a model can learn those problems. Supervised does not automatically mean correct or fair.

4. Unsupervised learning: find patterns without target labels

Suppose you have unlabeled pictures of fruit. An unsupervised method may group examples that are similar according to the features it sees, such as shape or color. But it does not automatically know that one group is “apples” and another is “bananas.” A person must interpret what the groups mean.

Unsupervised methods can help when answers are unknown, labels are unavailable or costly to create, or the goal is to explore structure. They can also reveal patterns people did not think to label in advance.

However, the groups or themes depend on the representation, method, settings, and data. An algorithm will find some structure even when that structure is not useful. Always check whether the result makes sense for the real question.

5. Where text representations fit in

For natural language processing (NLP), the lesson separates two broad levels of work:

  • Language-level representations: word or sentence/document embeddings capture patterns in language and can be learned without task-specific labels. A word vector may place words used in similar contexts near one another. It does not inherently know whether a word is emotionally positive; it learns from usage patterns.
  • Document-level organization: once documents are represented by useful features or embeddings, an analyst can use unsupervised methods such as topic modeling or cluster analysis to explore a corpus.

These ideas connect: raw text is hard to compare directly, so we represent it with features or vectors; then we can search for repeated themes or groups. The representation affects what patterns the method can discover.

6. Topic modeling vs. cluster analysis

QuestionTopic modelingClustering
What is organized? Themes or topics expressed across a corpus. Documents grouped by similarity.
What does a document receive? Usually a relevance score or proportion for each topic. A document can relate to multiple topics. Often one cluster assignment in a basic hard-clustering setup.
Best fit when you want to… Understand what themes are discussed and how much each document discusses them. Sort entire documents into groups of similar documents.
What you inspect Topic descriptions and a document-by-topic relevance profile. Representative documents and how coherent or useful each group is.

The course illustrates this with movie-related documents. Some discuss directors, theaters, and awards together; another may mix awards with agriculture or racing. A topic model can represent several themes in one document. A clustering method would instead group whole documents according to their overall similarity.

Useful nuance: the lecture contrasts topic modeling’s multi-topic profiles with clustering’s one label per document. That is a helpful introductory distinction for common methods. Some topic models produce distributions across topics, while some clustering approaches allow soft or overlapping memberships; not every method follows the simple one-label rule.

7. Real-world example: making sense of customer feedback

Illustrative example; not a measured result from the course. A shop has thousands of written comments about deliveries, product quality, refunds, and customer service.

Question A: “Is this comment about delivery?”

If staff can label a set of comments as delivery-related or not, use supervised learning to train a classifier to apply those known categories to new comments.

Question B: “What themes are customers discussing?”

If themes are not known in advance, topic modeling can help discover recurring themes and estimate which themes appear in each comment. One comment may mention both a late delivery and a damaged item.

Question C: “Which comments are similar overall?”

Clustering can group comments with similar content or representations. A group might collect delivery complaints while another groups compliments about product quality.

These methods answer different questions. If the business already has a clear category it needs to apply consistently, supervised learning is a natural candidate. If it wants to explore unknown structure, an unsupervised method may be more appropriate. A useful project may use both: discover themes first, then have people define labels and train a supervised classifier if those labels meet a real need.

8. A simple decision guide

  1. Do you know the answer you want for each example? If yes, and you have enough reliable labeled examples, consider supervised learning.
  2. Are you exploring an unknown set of patterns? If yes, consider unsupervised methods, and plan how people will interpret the results.
  3. Do documents contain multiple themes? Topic modeling may fit better if you want a multi-theme profile per document.
  4. Do you need to group whole documents by similarity? Clustering may fit better if the goal is a set of document groups.
  5. Can you inspect and validate the result? Plan to check topic meaning or cluster coherence with relevant examples and subject-matter knowledge.
Rule of thumb from the lesson: first ask whether a supervised method is possible. If the desired labels are clear and can be labeled reliably, training against those labels may be more directly aligned with the goal. Unsupervised methods are especially useful when the structure or categories are not known in advance.

9. Common mistakes and limitations

  • Assuming unsupervised groups have obvious names. The algorithm returns patterns or group assignments, not human explanations. Interpret them after examining examples.
  • Thinking “unlabeled” means “no decisions.” Feature choices, preprocessing, number of groups/topics, and similarity definitions all influence the result.
  • Confusing a topic with a cluster. A topic is a theme that can appear in many documents and alongside other themes; a cluster is a grouping of documents as a whole.
  • Assuming each document discusses only one topic. Documents often cover several subjects, which is why topic relevance scores can be useful.
  • Assuming more topics or clusters are automatically better. A large number can split meaningful patterns into confusing fragments; a small number can merge distinct patterns.
  • Treating discovered structure as objective truth. Unsupervised results depend on the data representation and modeling choices and should be validated for the intended use.
  • Calling a model “supervised” just because a person later names its clusters. The key distinction is whether target labels were supplied during training to guide the model.

10. Quick recap

  • Supervised learning: input features plus known target labels; learn to predict the target for new examples.
  • Unsupervised learning: input features without supplied target labels; explore patterns or organization in the data.
  • Topic modeling: discover themes and describe how relevant multiple topics are to each document.
  • Clustering: group whole documents by similarity, commonly assigning each document to one group in a basic hard-clustering method.
  • Choose from the question: known answer to predict → supervised; unknown structure to explore → unsupervised.

11. Self-check

Try to answer each question before expanding its explanation.

1. What is the key difference between supervised and unsupervised learning?

Supervised learning is trained with examples that include target labels; unsupervised learning explores data without those target labels supplied in advance.

2. A company has labeled examples of “urgent” and “not urgent” emails and wants to label new emails. Which type of task is this?

Supervised learning, because the desired labels are known in the training examples.

3. Why might topic modeling be a better fit than clustering when documents discuss several subjects?

Topic modeling can represent multiple topic relevance scores for a document, while a basic clustering approach groups the document as a whole.

4. Does a cluster automatically mean “customer complaint”?

No. A clustering method groups documents based on its features and settings. A person must inspect and interpret the group before assigning a useful description.

5. What does a word embedding learn from unlabeled text?

It learns a numerical representation from patterns in how words are used. Words used in similar contexts may receive similar representations, but the model does not automatically know a human-assigned sentiment label.

6. Could supervised and unsupervised methods be used in the same project?

Yes. For example, unsupervised methods can help explore themes, after which people may define useful categories and label examples for a supervised model. The methods answer different questions.
