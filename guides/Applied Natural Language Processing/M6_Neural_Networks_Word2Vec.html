1. A neural network is a chain of adjustable calculators

An artificial neuron takes input numbers, gives each input an adjustable importance (a weight), adds a bias, and applies an activation function.

weighted input + bias → activation → output

For example, a review classifier might receive numeric features related to “excellent,” “broken,” and “refund.” A learned positive weight for “excellent” can push the result toward “positive”; a negative weight for “broken” can push it toward “negative.” A real network learns these weights from examples rather than relying on rules we manually write.

Weights

Adjustable knobs that describe how much an input contributes.

Bias

An extra adjustable offset, so the model can shift its response.

Activation

A function applied after the weighted sum. Nonlinear activations let networks learn more than straight-line relationships.

Activations: different output behaviors

ActivationPlain-language behaviorCommon role in the M6 material
LinearLeaves the value unrestricted.Output for a continuous prediction, such as a price estimate.
SigmoidSquashes a value between 0 and 1.One probability for a yes/no prediction.
SoftmaxTurns class scores into probabilities that add to 1.Choose among several categories, such as billing, delivery, or account help.
ReLUChanges negative values to zero and leaves positive values unchanged.A common hidden-layer activation in deep networks.
TanhSquashes values into the range −1 to 1.One activation option discussed for hidden layers.

Important distinction: an activation does not itself make optimization easy by guaranteeing a convex loss. Nonlinear activations let the network represent nonlinear patterns; the choice of activations and optimizer affects training behavior.

Memory cue: Weight = importance; bias = starting nudge; activation = response shape.

Layers build up a prediction

  • Input layer: receives features as numbers.
  • Hidden layer(s): mix and transform features into useful intermediate patterns.
  • Output layer: produces the final score, probability, or category.

In a fully connected layer, each unit connects to every unit in the next layer. That flexibility can help fit complicated relationships, but adds parameters and can overfit when a model is too large for its data.

2. How the network learns: guess, compare, adjust

1. Forward passMake a prediction
→
2. LossMeasure the mistake
→
3. BackpropagationTrace which weights contributed
→
4. UpdateNudge weights to reduce future error

Forward pass: make the guess

The input travels from the first layer through hidden layers to the output. Each layer calculates weighted sums and applies its activation. For example, a message classifier might output probabilities: billing 0.15, delivery 0.75, account 0.10.

Loss: measure how wrong the guess was

A loss function compares the prediction with the correct answer. If the true class is “delivery,” a high probability for “delivery” generally means a smaller classification loss. Training tries to make the loss smaller.

Backpropagation: send learning signals backward

Backpropagation applies the chain rule to calculate how each parameter affected the loss, starting at the output and working backward through the network.

Gradient descent uses those gradients to update parameters a small amount in a direction intended to reduce the loss. The learning rate controls the step size: too large can make learning unstable; too small can make it slow.

Memory cue: Forward = predict. Backward = learn from the mistake.

Iterations, epochs, and batches

TermSimple meaningExample with 1,000 messages
IterationOne parameter update.One update after processing one message or one mini-batch.
EpochOne complete pass through the training set.After all 1,000 messages have been processed once.
Stochastic gradient descentUpdate using one example at a time.About 1,000 iterations in an epoch if using one message per update.
Mini-batch gradient descentUpdate using a small group at a time.With batches of 50, about 20 updates per epoch.
Batch gradient descentUpdate using all examples together.One update uses all 1,000; this may require substantial memory.

A small batch can balance memory use and update efficiency. These training styles describe how much data contributes to an update; they are not the same thing as the train/test split.

Overfitting: the model memorizes details of its training examples instead of learning patterns that transfer to new examples. A large network can overfit, especially with little data. A good training score alone does not prove the model will work on future messages.

3. How can we tell whether a text classifier is useful?

The M6 classification toolbox tests several algorithms on news-group categories. A measurement should match the practical cost of different mistakes.

Accuracy

Out of all predictions, what fraction was correct? Useful as a quick overview, but can hide failure on a rare class.

Precision

Of the items labeled as a category, what fraction truly belongs there? Important when false alarms are costly.

Recall

Of all the real items in a category, what fraction did the model find? Important when missing a case is costly.

F1 score

A combined measure that is high when both precision and recall are high. It is the harmonic mean, not an ordinary average.

Consider a support system flagging possible urgent safety complaints. Recall matters if missing a dangerous report is unacceptable. But if every message is flagged, the team is overwhelmed; precision matters too. Which metric matters more depends on how the system will be used.

Confusion matrix: see the mix-ups

A confusion matrix compares actual categories with predicted categories. Correct predictions lie along its diagonal; other cells show which categories were confused. For example, a news classifier might confuse two topic groups that use similar vocabulary.

ROC AUC, in simple terms

ROC AUC summarizes how well model scores rank positive examples above negative examples across decision thresholds. It is not the same as accuracy, and its precise interpretation depends on how a multiclass problem is evaluated.

Course classifier toolbox: it illustrates accuracy with a Perceptron, recall with linear SVM, precision with RBF SVM, F1 with Multinomial Naive Bayes, ROC AUC and a confusion matrix with Logistic Regression, and accuracy for a two-layer neural network. These are demonstrations of metrics and workflows, not evidence that each algorithm should only be judged by its assigned metric.

Fair evaluation: fit preprocessing (such as TF-IDF) on training data, then use that fitted transformation on test data. Use validation data for model choices, and reserve the test set for a final check. Repeatedly tuning against the test set makes the final score less independent.

4. Word vectors: from word labels to useful coordinates

Text models need numbers for words. One-hot encoding gives every vocabulary word its own vector position. With vocabulary [apple, orange, fruit, car], an encoding could be:

apple = [1, 0, 0, 0]    orange = [0, 1, 0, 0]

This identifies the word, but does not express that apple and orange are both fruits. Different words have no built-in similarity in their one-hot vectors. A vocabulary of one million words also means one-million-value vectors, mostly zeros.

A dense embedding represents each word with a shorter list of learned real numbers. In an embedding space, words used in similar contexts may end up with more similar vectors.

Real-world example: search. If someone searches for “automobile repair,” a system with useful word representations may connect it with text about “car maintenance.” It is using learned patterns in word usage—not looking up a guaranteed dictionary synonym.

Word2Vec is a method for learning such vectors from surrounding words. It makes training examples out of ordinary text, so it does not need a human to label every word as “car,” “fruit,” or “emotion.” This is called self-supervised learning.

Memory cue: One-hot says “which word?”; an embedding also learns “which words are used similarly?”

5. Word2Vec: two opposite guessing games

Word2Vec trains on short windows of neighboring words. It repeatedly asks one of two questions, adjusts its network to answer better, and uses a learned layer's weights as the word vectors.

CBOW: context predicts the center

Given the neighboring words, guess the missing word.

Memory hook: “Fill the blank from the surrounding clues.”

Skip-gram: center predicts context

Given one word, guess words likely to appear nearby.

Memory hook: “Start with the word; guess its neighbors.”

Walk-through: In “The cat sat on the mat,” look at cat with a window of one word on either side. CBOW uses nearby words such as “the” and “sat” to guess cat. Skip-gram uses cat to predict nearby words such as “the” and “sat.”
QuestionCBOWSkip-gram
InputWords around a targetOne center word
PredictionThe center wordNearby context words
Classic intuitionFill in the blankGuess the neighbors
Typical trade-offOften faster; combines context and can work well for frequent words.Often slower; can provide useful learning signals for less frequent words when there is enough data.

The course materials describe CBOW as tending toward broader or more syntactic associations and Skip-gram as capturing more specific semantic relationships. Treat that as a useful teaching intuition, not a universal rule: results depend on corpus size and quality, word frequency, context window, model settings, and the evaluation task.

What is the context window?

The window size controls how many nearby words count as context during training. A narrow window emphasizes closer neighbors; a wider window can include more distant context. The best choice depends on the corpus and goal.

Why does the training corpus matter?

An embedding only learns patterns it sees. In the toolbox, a model trained on the comparatively small 20 Newsgroups subset does not give convincing answers to every word relationship. The lesson compares it with a Gensim model trained on a vastly larger Google News corpus, which gives a much more plausible result for king + woman − man, such as “queen.”

This is a demonstration, not a guarantee that the analogy will always work. The result depends on how often the words appear and how they are used in the training text. Larger and more relevant data can help, but does not remove bias or make every vector arithmetic relationship meaningful.

Word similarity is a clue, not a dictionary

Cosine similarity compares the direction of two vectors. Words with similar context patterns may appear near each other in vector space. A small corpus can yield odd neighbors; a similarity score does not prove that two words have identical meanings.

Static embedding limitation: classic Word2Vec gives a word type one learned vector. So the word bank typically has one vector whether the sentence means a financial bank or a river bank. The vector combines uses found in the training corpus rather than changing for each sentence.
Fast recall: CBOW = context to center. Skip-gram = center to context.

7. One-minute recap

  1. A neural network combines numeric inputs with learned weights and biases.
  2. Activations help the network represent nonlinear patterns.
  3. Forward pass makes a guess; loss measures the error; backpropagation calculates learning signals; gradient descent updates parameters.
  4. One epoch is a pass through the training set; each iteration updates parameters using a batch of examples.
  5. Precision asks “Of the things I flagged, how many were right?” Recall asks “Of the real cases, how many did I find?”
  6. Word2Vec learns word vectors by predicting from context or predicting context from a word.
  7. CBOW predicts the center word; Skip-gram predicts its neighbors.
  8. Embeddings reflect patterns in their training corpus and can be biased, incomplete, or ambiguous.
Remember it in one breath: Predict, measure, update; context predicts center (CBOW), center predicts context (Skip-gram).

8. Quick self-check

Try to answer first; open each item to check yourself.

What is the difference between a weight and a hyperparameter?

A weight is learned from training data. A hyperparameter, such as hidden-layer size, learning rate, or context-window size, is selected as part of setting up or tuning the model.

What do “forward pass” and “backpropagation” mean?

The forward pass sends input through the network to make a prediction. Backpropagation works backward from the loss to calculate how parameters affected the error.

With 1,000 examples and a mini-batch of 50, about how many iterations make one epoch?

About 20 iterations, because each update processes 50 examples and one epoch processes all 1,000.

If missing an urgent message is worse than reviewing an extra one, which metric should you pay close attention to?

Recall: it measures how many real urgent messages the model successfully finds. You should still inspect precision to understand the false-alarm burden.

How does CBOW learn the word “cat” in “the cat sat” with a one-word window?

It uses the neighboring context—“the” and “sat”—to predict the center word “cat.”

What does Skip-gram do with the word “cat” in the same sentence?

It uses “cat” as the input and tries to predict its nearby context words, such as “the” and “sat.”

Why might a small-corpus model fail the “king + woman − man” analogy?

The words may be rare or have too few varied examples for reliable relationships to be learned. Word-vector arithmetic depends on the model and corpus; it is not guaranteed.

Why does classic Word2Vec not automatically distinguish the two meanings of “bank”?

It assigns one static vector to the word type, so the vector combines uses rather than changing with each sentence's context.
